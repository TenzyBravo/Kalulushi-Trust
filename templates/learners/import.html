Import learners from CSV

Every row is checked first. If any row has a problem, nothing is saved and each problem is listed by line. Learners go into classes of the current academic year.

File format

Required columns: first_name, last_name, gender, class, guardian_name, guardian_phone.

Optional: other_names, date_of_birth, registration_date (YYYY-MM-DD or DD/MM/YYYY), previous_school, guardian_email, relationship.

class is the class name, e.g. 4A or F1B. The guardian becomes the primary contact. A guardian already saved with the same name and number is linked rather than created again.
